# ADR-0001: Модульный монолит для backend

- Статус: принято
- Дата: 2026-08-21

## Контекст

Tracker содержит связанные домены организаций, проектов, задач и сессий. Их согласованность опирается
на общую PostgreSQL transaction boundary. Команда и нагрузка пока не оправдывают операционную стоимость
распределённой системы.

## Решение

Оставить NestJS API модульным монолитом. Каждый доменный модуль владеет controller/service/repository и
публично экспортирует только service или явный interface. Другие модули не импортируют его repository.
Frontend, API и data services развёртываются отдельными контейнерами.

## Последствия

- Проще транзакции, локальная разработка и наблюдение за request flow.
- Меньше сетевых failure modes и дублирования контрактов.
- Требуется дисциплина импортов и владения данными.
- Модуль можно извлечь только при наличии измеримой причины: отдельный scale profile, SLA или ownership.
- Межпроцессные гарантии в будущем потребуют outbox/idempotent consumers.

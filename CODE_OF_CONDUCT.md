# Code of Conduct

## Наши стандарты

Участники проекта обязуются общаться уважительно, обсуждать идеи по существу, принимать конструктивную
обратную связь и учитывать разный опыт собеседников. Недопустимы преследование, угрозы, дискриминация,
публикация чужих персональных данных и намеренное нарушение безопасности проекта.

## Применение

Maintainer может редактировать или удалять материалы, ограничивать участие и блокировать пользователей,
если поведение в репозитории, Discussions или связанных каналах нарушает эти правила.

О проблеме поведения сообщайте maintainer приватным способом через профиль владельца репозитория. Не
используйте security advisory для межличностных конфликтов. Сообщение будет рассмотрено конфиденциально
и соразмерно обстоятельствам.
